星云 Shader 使用说明
====================

1. 创建材质
   - 在 Project 中右键 -> Create -> Material，命名为例如 "Nebula"
   - 在 Inspector 里将 Shader 选为：Custom/Nebula

2. 用法（二选一）
   A) 天空球：在场景里建一个较大的球体（Scale 如 500,500,500），将球体翻转（Scale 设为负的 X 或翻转法线），把 Nebula 材质赋给该球体，相机在球体内部即可看到星云背景。
   B) 天空盒：若使用 6 面天空盒，可为每个面使用同一 Nebula 材质（效果会随视线方向变化）。

3. Inspector 可调参数
   - 深色/中间色/亮色/星点高亮：星云颜色渐变与星点颜色
   - 噪声尺度、噪声层数、层间衰减：控制云状形态的疏密与层次
   - 星云密度、明暗锐度：整体浓淡与对比
   - 星点尺度/阈值/亮度：背景星点的大小与密度
   - 启用缓慢漂移、漂移速度：星云缓慢动画（可选）

4. 性能
   - 噪声为程序化计算，层数（Octaves）越大越细腻但越耗性能，建议 3~4。
