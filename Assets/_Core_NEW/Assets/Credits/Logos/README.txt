Supporters' logos for the credits (PC_Credits > Credits > Supported By).

Put each supporter's own logo file here - the version its maker supplies for dark
backgrounds (white or reversed), PNG with a transparent background, at least 800 px wide.
In Unity set its Texture Type to "Sprite (2D and UI)", then drag it onto that supporter's
Logo slot. A supporter with no logo is set as its name in words.

Use the files each organisation publishes or sends, unaltered, and under its own terms.
